# Development stage 1 (2026-09-23, 11:58–12:24 BST): archived snapshot, superseded

The first development batch: 18 episodes, 36 calls, hard group at 40 points, original prompt wording. **Superseded and void for the development gate.** A retroactive audit of the raw traces (`advisor_audit.json`) found that a server-side "advisor" tool consulted `claude-fable-5-1` inside 24 of these 36 calls (16 of 18 episodes), under `--tools ""`. V1's controls did not look for server-side tools or for a second model in the reported usage, so these episodes passed as valid. Under the amended V2 controls they are `invalid_run`. The two gate decisions taken on this stage were handled as follows: the escalation of the hard group to 60 points was **reverted** (hard = 40 again), and the prompt-wording revision ("no code fences, no other text", made after one fenced-JSON reply here) was **kept** as the one revision the gate allows.

Everything in this folder (episodes, the task/key/plan files it used, and the summary and chart generated from it before the discovery) is an unchanged snapshot, not a CI target and not evidence about `claude-opus-5` alone. The clean development run is stage 3, in `results/v2/episodes_dev.jsonl`.
